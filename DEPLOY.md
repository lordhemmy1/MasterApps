# Stockdity IMS — Deployment Guide

Quick reference for deploying Stockdity IMS to various environments.

---

## Pre-Deployment Checklist

Before deploying to any environment, ensure you have:

- [ ] Updated `config.js` with the customer's `LICENCE_KEY_HASH`
- [ ] Updated `config.js` with `APP_NAME`, `DEFAULT_CURRENCY_SYMBOL`,
      `DEFAULT_TIMEZONE`
- [ ] Verified the app works locally (see Local Development below)
- [ ] Confirmed all files are present (see File Checklist below)
