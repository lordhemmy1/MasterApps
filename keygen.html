Delivery Checklist
Before sending the application files to the customer, verify:
  • The SHA-256 hash has been pasted into config.js → LICENCE_KEY_HASH
  • APP_NAME updated with the customer's business / product name
  • DEFAULT_CURRENCY_SYMBOL set for the customer's country
  • DEFAULT_TIMEZONE set correctly (e.g. Africa/Lagos)
  • This keygen.html file is NOT included in the delivery zip
  • The licence key has been sent to the customer separately (not in the files)
  • Customer has been told the default admin credentials and to change them
