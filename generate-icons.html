🎨 Stockdity IMS — Icon & Image Generator

Generate all required PNG icon sizes and placeholder images for the application.
Everything runs in your browser — no uploads, no servers.

⚠️ Seller / Developer Tool. Do not include this file in the customer delivery package. Run it once, download the images, then place them in assets/images/.
  1. Choose a background colour (default matches the app's primary colour)
  2. Optionally upload your own logo/icon image (square PNG or SVG recommended)
  3. Click Generate All Icons
  4. Download each icon and save it to assets/images/ with the exact filename shown
  5. For favicon.ico: download the 32×32 PNG and convert at convertio.co

These should match your config.js → DEFAULT_PRIMARY_COLOR
